Paper pattern Add sections only if your paper uses them

Each "question group" describes a batch of similar questions — e.g. "5 MCQs of 1 mark each" or "3 long-answer questions, attempt any 2". Add parts (a), (b), (c) inside a group if a question is split, and mark a group as a choice if not every question in it is compulsory.

Write your blueprint

Type it exactly how you'd like it to appear on the paper, one line per question type — for example:
"MCQs: 10 x 1 = 10 marks"
"Short Answer (attempt any 2 out of 3): 3 marks each"
We save this exactly as you type it, with no calculations of our own.
